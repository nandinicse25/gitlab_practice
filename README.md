# eCommerce Dashboard Project

A complete runnable eCommerce dashboard project built with HTML/CSS/JavaScript and served with Python's standard library.

## Run the project

```bash
cd ecommerce_dashboard
python server.py
```

Open: http://127.0.0.1:8000

## Project structure

- `ecommerce_dashboard/index.html` — dashboard layout
- `ecommerce_dashboard/static/styles.css` — UI styles
- `ecommerce_dashboard/static/app.js` — dashboard data + rendering
- `ecommerce_dashboard/server.py` — local HTTP server
